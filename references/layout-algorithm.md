# 布局算法

## 测量与分侧

用真实中文字体按深度测量文本并加入 padding。同一父节点下且深度不超过 L3 的兄弟统一为该组最宽卡片宽度。

`subtree_h(n) = max(n.h, sum(subtree_h(child)) + child_gap × (k-1))`

按一级阅读序号分侧，奇数放右、偶数放左。右侧可以多一枝，不要为枝数相等移动末枝。同侧一级按原序号从上到下排列。

## 分组排布

使用固定间距。令 `block_h = sum(subtree_h) + gap × (n-1)`，列顶为 `cy - block_h/2`，并限制到至少 36px 页边距。一级节点在自己的子树高度内垂直居中。

同侧一级内边对齐，并按分组中心光学外移：`stagger = min(48, 28 × (abs(cluster_cy - cy) / cy) ^ 1.15)`。

右侧 `x = cx + ROOT_R + RING_GAP + stagger`；左侧 `x = cx - ROOT_R - RING_GAP - width - stagger`。子节点放在父节点外侧，子列相对父节点垂直居中，并按各子树高度递归向下排。

## 碰撞与连线

为每条一级枝计算包含后代的 AABB。同侧重叠时将下方整枝下推，使间距至少 26px，最后整体限制在至少 20px 画布边距内。

根到一级使用三次贝塞尔。起点为朝向一级的根圆周点，控制点 1 沿半径外移约 64px，控制点 2 从一级内侧水平内收约 50px，终点落在胶囊内侧中点。使用枝色、3px、圆头、约 0.78 透明度。

父到子使用正交脊骨：从父外侧水平走 9–12px，垂直覆盖全部子中点，再水平进入子节点。深度线宽依次为 1.7、1.35、1.15、1.0px。

验收同侧 L1 内边基本一致且 stagger 不超过 48px；同父 L1–L3 兄弟等宽；同侧一级枝 AABB 间距至少 26px；所有标签水平，连线不穿过根圆或非所属卡片。
